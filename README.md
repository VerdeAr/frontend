# Verdear — Frontend

Aplicação web do sistema **Verdear**, marketplace de produtos orgânicos e da agricultura familiar, que consome a API do repositório [`backend`](https://github.com/VerdeAr/backend).

Este repositório substitui as views do monolito legado [`Verdear`](https://github.com/VerdeAr/Verdear), que segue ativo em paralelo durante a migração.

## Documentação

- [Arquitetura e stack](./docs/ARQUITETURA.md)
- [Fluxo de Git (GitLab Flow)](./docs/GITFLOW.md)

## Rodando localmente

```bash
npm install
npm run dev
```
